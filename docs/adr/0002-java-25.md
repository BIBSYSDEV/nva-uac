# ADR 0002: Java 25 toolchain

Date: 2026-10-18

Status: Accepted

## Context

The plan and the other NVA services assume Java 21. Java 25 is the current long-term-support
release, and every gate that previously kept NVA on 21 is open: AWS Lambda has a `java25`
managed runtime with SnapStart since November 2025, Quarkus supports Java 25 fully from 3.31,
CodeBuild offers `corretto25` on the current Amazon Linux 2023 images, the shared BIBSYSDEV
Java workflow takes the version as an input, and the shared NVA Gradle plugins take it as a
setting.

## Decision

nva-uac compiles and runs on Amazon Corretto 25. The version is set once, in the Java
convention plugin under `buildSrc`, and every module inherits it. Error Prone, PMD, JaCoCo and
the formatter are the versions bundled with the shared plugins, all of which support Java 25.

## Consequences

The `java25` Lambda runtime and a Java 25 base image for EKS are used from Phase 0. A native
executable, if Phase 0 ever calls for one, is built with Mandrel for JDK 25. Should a tool fall
behind, moving back to 21 is a one-line change and a superseding record.
